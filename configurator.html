Interactive Book - Hotspot Configurator

How to Use:

  1. Load your PDF file using the file input below
  2. Navigate to the page where you want to add a hotspot
  3. Click and drag on the PDF to create a selection box around the area
  4. Fill in the hotspot details in the form
  5. Click "Add Hotspot" to save it
  6. Repeat for all pages and hotspots
  7. Copy the generated JSON and paste it into your config.json file
