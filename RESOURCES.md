  - Filter by "Downloadable"
  - GLB export available

## Model Conversion Tools

### Online Converters
- **Aspose 3D Converter** - https://products.aspose.app/3d/conversion
  - Any format to GLB/USDZ
  - Free online tool

- **glTF Viewer & Converter** - https://gltf.report/
  - View and optimize GLB files
  - Compression options

### Desktop Tools
- **Reality Converter** (Mac only) - https://developer.apple.com/augmented-reality/tools/
  - Convert to USDZ for iOS
  - Free from Apple

- **Blender** - Can convert between most formats
  - Import any format
  - Export as glTF 2.0

## Model Optimization

### Why Optimize?
- Faster loading times
- Better mobile performance
- Reduced bandwidth usage

### Tools
- **gltf-pipeline** - https://github.com/CesiumGS/gltf-pipeline
  - Command-line tool
  - Draco compression
  - Texture optimization

- **glTF Report** - https://gltf.report/
  - Web-based optimizer
  - Visual comparison
  - Compression stats

- **Blender Export Settings**
  - Enable Draco compression
  - Limit texture size (1024x1024 or 2048x2048)
  - Remove unused materials
